# 검증 결과 — 2026-09-16

환경: Xcode 26.6, iPhone 17 Pro Simulator / iOS 26.5. Deployment target: iOS 16.0.

## 통과

- 앱 및 Share Extension 시뮬레이터 빌드 성공. 최종 실행 빌드는 `CODE_SIGN_IDENTITY=-`로 ad-hoc 서명.
- XCTest 6개 통과: 이미지·메모 저장 후 재로드, 메모 수정, 삭제, 잘못된 이미지 거부, 별도 저장소 인스턴스 두 개에서 저장한 항목 보존, SUIT Regular/Bold 등록 확인.
- 초기 unsigned 실행에서 App Group 접근 실패를 실제로 확인했고, ad-hoc 서명을 적용해 해결. 저장 실패를 성공으로 처리하거나 개인 컨테이너로 우회하지 않음.
- HIG 기반 inset-grouped 보관함 목록과 메모 우선 상세 화면 확인. 작은 썸네일, 항목 수, 필터, 날짜 및 전체 이미지 표시를 재검증.
- 상세 메모 편집 → 저장 → 재편집 시 최신 메모 유지 → 보관함 반영 → 입력한 문자열 검색까지 실제 UI에서 확인.
- 미저장 메모가 있는 편집 시트를 취소할 때 폐기 확인이 표시되는 것을 검증.
- Photos에서 직접 생성한 테스트 이미지 → 공유 → Screenshots 확장 → 메모 입력 → 저장 → 본앱에서 메모 검색 및 이미지 표시까지 확인.
- 앱 재실행 후 공유 확장 항목을 포함한 4개 테스트 레코드 유지 확인.
- 라이트·다크 모드에서 목록과 텍스트 대비, 검색 UI 확인. 최대 접근성 글자 크기에서 행이 세로로 바뀌고 필터가 메뉴형으로 바뀌는 것을 확인. previews 폴더에 캡처 저장.
- 수정한 공유 확장에서 메모를 먼저 입력하고 미리보기를 확인한 뒤 저장했으며, 본앱의 5번째 항목으로 반영되는 것을 재검증.
- iOS 26용 스크린샷 자동화 설정 안내와 공식 `shortcuts://` 앱 바로가기를 추가한 뒤 앱 빌드와 XCTest를 다시 통과.
- iOS 26 앱 시작 시 전체 화면 자동화 온보딩이 열리고 단계 진행 상태가 앱을 오가는 동안 유지되는 것을 실제 UI에서 확인. `나중에` 선택 후 다음 실행에서도 온보딩이 숨겨지는 상태도 확인.
- 설정을 2단계로 축소. `최근 스크린샷에 메모` App Shortcut이 최근 스크린샷 조회, 필수 메모 질문, 앱 저장을 한 번에 처리하며 빌드 메타데이터와 자연어 훈련 데이터 생성까지 확인.
- 공식 SUIT Variable TTF를 앱과 공유 확장에 포함하고 SUIT 기반 Dynamic Type 위계를 적용. 일반 글자 크기, 최대 접근성 글자 크기, 라이트·다크 모드에서 온보딩과 보관함 레이아웃을 실제 시뮬레이터로 확인.
- 2단계 설정 화면에 진행률, 정확한 App Shortcut 이름 복사, 사진 권한 없이 공유 방식으로 계속하는 선택지를 추가해 설정 중 이탈과 권한 부담을 줄임.
- 자동화 직후 PhotoKit 인덱싱 지연을 고려해 최근 스크린샷 조회를 최대 약 3초 재시도하도록 보완하고, 10분이 지난 이미지는 잘못 연결하지 않도록 제한. 시뮬레이터에서는 `simctl addmedia`로 넣은 최신 일반 이미지도 테스트 대상으로 인식하도록 처리.
- 최신 빌드를 iOS 26.5 시뮬레이터에 덮어 설치하고 시뮬레이터 캡처 PNG를 Photos에 추가해 최근 이미지가 존재하는 테스트 상태를 구성. 빌드와 XCTest 6개를 다시 통과.
- 개인 Apple Developer 계정으로 앱과 공유 확장 프로비저닝을 생성하고 iOS 26.7 실기기 iPhone 17 ‘만수’에 설치. 사용자가 개발자 프로파일을 신뢰한 뒤 앱 프로세스가 정상 실행되는 것을 `devicectl`로 확인.

## 미검증 / 제한

- iOS 16~18 런타임 및 iPad 실제 화면은 미검증. 최소 버전 호환성은 컴파일 기준.
- 단축어 App Intent는 빌드되고 메타데이터가 생성되었으나 실제 Shortcuts 액션 연결과 실행은 미검증.
- Apple이 공식 문서화한 iOS 26 스크린샷 자동화와 앱의 App Intent를 연결하는 안내는 구현. 개인용 자동화 자체는 앱이 설치할 수 없으며, 사진 권한 허용과 자동화 연결 후의 실기기 전체 흐름은 사용자의 기기 조작을 통해 확인해야 함.
- 표준 크기와 최대 접근성 글자 크기는 확인했으나 중간 단계별 모든 크기와 VoiceOver 완주 검증은 미완료.
- 공유 확장은 한 장의 이미지 입력만 지원.
- 메모·이미지는 로컬 저장. 내보내기·클라우드 동기화·OCR 검색은 미구현.

검증 데이터는 직접 생성한 데모 이미지 및 앱 아이콘입니다. 사용자 사진은 사용하지 않았습니다. UI 테스트에서 쓴 QA 문구는 검증 후 테스트 레코드에서 읽기 쉬운 샘플 문구로 정리했습니다.

## 2026-09-18 (iOS 27 실기기 · iPhone 17 '만수')

- 단축어 **자동화** 탭에 `스크린샷` 트리거가 실제로 존재하고 동작함을 실기기에서 확인. iOS 27 트리거 표기는 `사진, 파일 또는 클립보드에 스크린샷을 저장할 때`.
- 자동화 생성 경로 확인: `자동화` 탭 → 아래 가운데 `+` → 오른쪽 위 `편집` → 검색창 `자동화` 칩 → `스크린샷` → 동작 `최근 스크린샷에 메모`.
- **`왜 저장했나요?` 입력을 취소해도 캡처가 저장되는 것을 실기기에서 확인** (인텐트를 "먼저 저장 후 질문" 순서로 변경한 결과).
- `shortcuts://automations` 딥링크가 자동화 탭을 여는 것을 확인. 단수형 `shortcuts://automation`은 동작하지 않고 앱의 마지막 상태로 열림. `shortcuts://create-automation`은 자동화가 아닌 **새 보관함 단축어**를 만들어 사용하지 않음.
- 표시 이름 `Shotchive`, 강조색 `#12379E`(다크 `#7AA5FF`) 적용 확인.
- 개별 스크린샷 공유가 `JPEG 이미지`로 인식되는 것을 확인(저장 시 확장자 없는 파일을 매직 바이트로 복원).
- 보관함 내보내기 zip 내용물 확인: `메모.md`, `captures.json`, `images/*.jpg`.
- 배포 설정: deployment target `iOS 26.0`, **iPhone 전용**(`TARGETED_DEVICE_FAMILY=1`), 세로 고정. 앱·공유 확장 각각에 `PrivacyInfo.xcprivacy` 포함(추적 없음, 수집 없음, 앱만 `UserDefaults`/`CA92.1` 선언).
- **iOS 26.5 시뮬레이터 확인 결과**: 단축어 앱은 시뮬레이터에 존재하며(`com.apple.shortcuts`) 자동화 탭과 `shortcuts://automations` 딥링크 모두 동작함. 다만 트리거 목록의 앱 그룹에 `앱`·`지갑`만 있고 **`스크린샷` 트리거가 없음**. iOS 27 실기기에서는 같은 그룹에 `앱`·`지갑`·`스크린샷`·`알림`이 모두 표시됨.
- 위 결과로 보아 스크린샷 자동화 트리거는 **iOS 27 기능일 가능성이 높음**. iOS 26 실기기 미확인.
- 앞선 기록의 "시뮬레이터에 단축어 앱이 없다"는 서술은 **오류**였음.
